# Les fichiers de la Base Adresse Nationale

Les fichiers des adresses, découpées par département, sont mis à disposition **chaque jour,** sur la [page des données nationales](https://adresse.data.gouv.fr/donnees-nationales).

La Base Adresse Nationale est versée une fois par semaine dans [OpenAdresses](https://openaddresses.io/) qui alimente notamment les opérateurs internationaux - GPS, *etc*.

### Format .csv pour un usage classique

#### [Schéma des données “Adresses”](https://github.com/BaseAdresseNationale/adresse.data.gouv.fr/blob/master/public/schemas/adresses-csv.md) au format CSV

Le séparateur point-virgule et l'encodage UTF-8 sont utilisés.
