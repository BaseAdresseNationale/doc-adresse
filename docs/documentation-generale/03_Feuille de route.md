# Feuille de route

Les évolutions sont priorisées pour les usages, en tenant compte de la **plus-value pour les communes, afin de favoriser l'avancée du "dites-le nous une fois de l'adresse" et la réutilisation des adresses**. Elles sont consultables sur les projets Github [adresse.data.gouv.fr](https://github.com/etalab/adresse.data.gouv.fr/projects/1) et [editeur-bal ](https://github.com/etalab/editeur-bal/projects/1)et ouvertes à contribution. La Base Adresse Nationale est **libre, open source et collaborative**. 

## Base Adresse Nationale

Pour suivre les développements de la BAN à venir et y contribuer, [la page Github de la feuille de route BAN](https://github.com/orgs/BaseAdresseNationale/projects/4/views/3) constitue l'entrée actualisée en temps réel. Certaines analyses font l'objet de discussions participatives dans le cadre de la démarche Adresse-Lab.
