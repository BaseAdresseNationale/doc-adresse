Le format Base Adresse Locale permet de préciser la ou les parcelle(s)
associée(s) à une adresse ou à un hameau ou lieu-dit


Le champ **cad\_parcelles** permet de préciser pour chaque adresse, la ou les parcelles cadastrales desservies ou représentées par cette adresse. Si le champ contient plusieurs parcelles, elles doivent être séparées par un pipe (|).

L'éditeur en ligne [Mes Adresses](https://mes-adresses.data.gouv.fr/) permet de renseigner ce champ à travers deux actions : une fois le fond de carte du cadastre sélectionné, il faut sélectionner un numéro et cliquer sur la ou les parcelles qui doivent lui être associées.
