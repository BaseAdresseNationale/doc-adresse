Une fois le formulaire de création complété, la Base Adresse Nationale adresse un courriel contenant le **lien de gestion de la BAL** avec le jeton d’administration expert qui permet d’être identifié comme administrateur. Nul besoin de mot de passe pour accéder à la Base Adresse Locale. L’autorisation de modifier définitivement les adresses d’une commune est accordée en fin de processus, à l’étape de la publication, après authentification de la commune.
