S’il existe déjà une Base Adresse Locale créée sur « Mes Adresses » pour la même commune avec le même mail, un message d’informa-tion s’affiche. L’objectif est d’encourager une commune à ouvrir la Base Adresse Locale qu’elle a déjà créée plutôt que d’en créer une nouvelle, ce qui génère un conflit. Si une Base Adresse Locale est déjà publiée dans la Base Adresse Nationale pour la commune en provenance du moissonneur ou de l’API de dépôt, aucun message ne s’affiche. Il est donc important de vérifier l’état des adresses avant de commencer (voir le [Parcours de l’adresse](/docs/documentation-generale/Mettre%20à%20jour%20sa%20Base%20Adresse%20Locale/Schéma%20du%20parcours)).

Deux solutions sont offertes :

- Poursuivre le travail sur la Base Adresse Locale préexistante en cliquant sur le bouton "Gérer mes adresses" pour la retrouver ;
- Créer une nouvelle Base Adresse Locale\

:::info
Pour rappel, seule une Base Adresse Locale en mode brouillon peut être supprimée. \
Si elle est "Prête à publier", il faut donc l'ouvrir dans l'éditeur et cliquer sur "Publier" puis revenir au mode brouillon. \
Une fois la Base Adresse Locale en mode boruillon, cliquer sur la Marianne pour afficher l'ensemble des Bases Adresse Locales et placer dans la corbeilles celles qui sont obsolètes. \
Pour supprimer une Base Adresse Locale publiée, contacter le support adresse@data.gouv.fr
:::
