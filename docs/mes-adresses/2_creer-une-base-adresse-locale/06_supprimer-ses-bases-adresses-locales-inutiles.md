---
title: "Supprimer ses Bases Adresses Locales inutiles"
---

Une seule Base Adresse Locale est publiée dans la Base Adresse Nationale. Si la commune a réalisé plusieurs essais, les Bases Adresses Locales inutilisées doivent être supprimées.

Cette opération se fait sur la page d’accueil de [Mes Adresses](https://mes-adresses.data.gouv.fr/) en plaçant les BAL en brouillon dans la corbeille.
