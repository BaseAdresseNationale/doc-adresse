---
title: "Consultez les demandes"
---
Dans Mes Adresses, vous pouvez acceder aux demandes reçues sur votre commune en cliquant sur le plot. Si vous ne voyez pas le plot, c'est que votre commune n'a pas encore reçu de demandes d'amélioration des adresses.

![signalements_plot_mesadresses](https://github.com/user-attachments/assets/6fab76cf-fffd-47c5-a4cf-90893949676f)

Vous avez alors la liste de l'ensemble des demandes classifiées avec un code couleur :
- création d'une adresse manquante
- modification d'une adresse existante
- suppression d'une adresse

![signalements_liste](https://github.com/user-attachments/assets/1b07fdb7-6b97-4518-9463-e1fd57fce6be)
